# Шпигун

Гра для компанії на 3–8 людей. Один екран (ноутбук, телевізор, планшет) веде раунди, телефони — пульти гравців. Встановлювати нічого не треба: усе працює в браузері.

## Як грати

1. Відкрий сайт гри на ноутбуці. З'явиться кімната з кодом (наприклад `KXPR`) і QR-код.
2. Гравці сканують QR або відкривають сайт і вводять код кімнати. Можна з будь-якої мережі.
3. Коли зайдуть 3+ гравці — «Почати гру».

## Правила

Усі бачать **тему й локацію**, шпигун — **лише тему**.

1. **Імена.** Кожен пише ім'я персонажа з натяком на локацію. Відкриваються одночасно.
2. **Питання по колу.** Кожен обирає, кого спитати, питання й відповідь — уголос.
3. **Додатковий раунд** (випадково): **малювання** (кожен малює локацію ~1 хв, потім усі малюнки на екрані) або **предмети** (по черзі береш предмет і пояснюєш зв'язок із локацією).
4. **Голосування.** Найбільше голосів — вибуває. Нічия — переголосування, знову нічия — ніхто не вибуває.
5. **Шанс шпигуна.** Після кожного голосування (навіть якщо його вигнали) шпигун може написати локацію. Мирні чесно вирішують, чи зарахувати. Вгадав — переміг, помилився — програв.
6. **Одне слово** про локацію від кожного.
7. **Друге голосування** і знову шанс шпигуна.

Шпигун перемагає, якщо вгадав локацію, пережив обидва голосування або лишилось двоє гравців.

## Локації

241 локація в 95 темах (`data.js`). Зіграні локації запам'ятовуються в браузері ведучого й не повторюються, поки не зіграєте всі.

## Хостинг (Render, безкоштовно)

New → Web Service → цей репозиторій → Runtime **Node**, Build Command порожній (або `npm install`), Start Command `node server.js`, план **Free**. Залежностей немає.

На безкоштовному плані сервер засинає після 15 хв без гравців — перше відкриття після паузи триває близько хвилини.

## Локальний запуск

`node server.js` (або `start.bat`), далі http://localhost:3000. Телефони мають бути в тій самій мережі; якщо Windows блокує — `open-firewall.bat`.

Таймери етапів — на початку `server.js` (об'єкт `SEC`).
